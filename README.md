This is the repo for RHyCAM Lab at University of Oklahoma. A special thanks to Allan Lab for sharing their template!


## Local build and styles

Run `bundle install`, then `bundle exec jekyll serve` to preview the site or
`bundle exec jekyll build` to build it.

The bundled Bootstrap 3 / Bootswatch Sass has been migrated to Sass modules
(`@use` / `@forward`), namespaced built-in functions, and `math.div()`.
Keep these local changes when updating the bundled styles; replacing them with
upstream Bootstrap 3 Sass will reintroduce deprecated syntax. No deprecation
warnings are suppressed in the build configuration.
